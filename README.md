# Password Security Analysis

**Internship:** Veda Technology — Cyber Security Track
**Task:** Day 4 — Password Security Analysis
**Author:** Ritu Raj

## Objective
Understand strong authentication practices by analyzing password security principles and designing a set of organizational password guidelines.

## Overview
Weak or reused passwords remain one of the leading causes of account compromise and data breaches. This task analyzes core principles of password security and translates them into a practical policy an organization could adopt.

## Key Areas Covered

### 1. Password Length & Complexity
- Length matters more than complexity — a 12+ character passphrase is harder to crack than a short, symbol-heavy password.
- Avoid predictable patterns (e.g. `Name123!`, `Password2024`).

### 2. Uniqueness
- No password reuse across accounts or systems.
- Reused credentials mean one breach compromises multiple accounts (credential stuffing risk).

### 3. Password Managers
- Recommended for generating and storing long, unique passwords per account.
- Removes the burden of memorization, reducing the temptation to reuse or simplify passwords.

### 4. Multi-Factor Authentication (MFA)
- Adds a second verification layer beyond the password (authenticator app, hardware key, SMS/email code).
- Significantly reduces risk even if a password is compromised.

## Interview Questions Addressed
- **What makes a password strong?** Length, unpredictability, and uniqueness — not just special characters.
- **Why should passwords be unique per account?** To prevent a single breach from cascading across multiple services.
- **What is MFA?** A security process requiring two or more independent verification factors (something you know, have, or are) to confirm identity.
